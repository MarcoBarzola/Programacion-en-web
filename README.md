# Programacion-en-web
<h1>Proyecto programacion en web en la uag</h1>
<h2>Descripcion</h2>
<p>
El sistema realiza la promocion de informacion de la renta de vehiculos de la empresa renta de carros XYZ
el cual le permite al usuario visualizar diferente informacion respecto ala empresa tales como:
</p>
<ul>
<li>index</li>
<li>conocenos</li>
<li>contacto</li>
</ul>

<h3>Index</h3>
<p>Muestra una breve bienvenida de la empresa a los usuarios para darles una idea a grandes rasgos de que 
se trata</p>

<h3>conocenos</h3>
<p>
Muestra quienes es la empresa por medio de su proposito,historia, mision ,vision,valores para dar una introduccion
mas detallada a nuestros clientes</p>

<h3>contacto</h3>
<p>Muestra informacion mas puntual de la empresa para como contactarlos asi como un formulario de envio de mensaje
para responder dudas</p>
